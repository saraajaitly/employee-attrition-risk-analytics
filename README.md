# Employee Attrition Risk Analytics

## 📌 Project Overview

This project predicts employee attrition using machine learning models and provides HR professionals with actionable insights through an interactive Streamlit dashboard.

The project includes:

- Data Audit & Exploratory Data Analysis
- Data Preprocessing
- Baseline Machine Learning Models
- Feature Selection
- Hyperparameter Tuning
- SHAP Explainability
- Interactive Streamlit Application
